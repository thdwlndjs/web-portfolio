## 9. 구현 승인 후 테스트/검수 전략

- **기능 TDD**: Red → Green → Refactor. 선택/포커스, 아코디언 1개만 열림, 링크, 이미지 누락, reduced-motion, 포커스 이동 등을 우선.
- **시각 검증**: 1440/1280/768/390/375px 스크린샷과 주요 인터랙션 상태별 캡처. 픽셀 차이만으로 미적 품질을 판정하지 않음.
- **콘텐츠 검증**: 포트폴리오 본문과 프로젝트/학력/수상 근거를 대조. 검증되지 않은 사실을 꾸미지 않음.
- **승인 게이트**: Phase 1 문서 검토 → 구현 승인 → TDD/Visual QA → 사용자 최종 시각 승인. 테스트 통과는 디자인 승인과 다름.
