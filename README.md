# Codex용 포트폴리오 디자인 컨텍스트 패키지

현재 포트폴리오 리디자인 대화에서 **유효 명세 / 결정 이력 / 논의 맥락**을 분리한 패키지입니다.

## 설치

압축파일 내부 폴더 구조를 **그대로** 아래 프로젝트 루트에 복사하세요.

`C:\Users\aicam\Desktop\웹포트폴리오\`

```text
웹포트폴리오/
├── AGENTS.md                         ← Codex 자동 진입점
└── docs/
    └── design/
        ├── redesign-spec.md          ← 현재 유효한 명세·수용 기준
        ├── decisions.md              ← 무엇을 왜 선택했는지
        └── discussion-archive.md     ← 대화 흐름 재구성/기각안 추적
```

프로젝트에 기존 `AGENTS.md`나 같은 이름의 파일이 있으면 **덮어쓰기 전에 내용을 병합**하세요. 프로젝트 루트가 다른 경우 실제 루트 기준으로 위치를 조정하세요.

## Codex에 최초 1회 입력할 명령

> 현재 작업 공간에서 `AGENTS.md`를 먼저 읽고, `docs/design/redesign-spec.md` → `decisions.md` 순서로 확인해 주세요. `discussion-archive.md`는 충돌·모호한 항목의 근거를 찾을 때만 해당 절을 참고하세요. 지금은 **Phase 1 Audit & Specification만** 진행합니다. 기존 소스 루트와 `/redesign-preview/` 원본 소스를 확인하고, 명세 대비 준수/불일치/미구현/확인 불가 표와 테스트·시각 검증 계획을 보고하세요. 승인받기 전 구현·배포는 하지 마세요.

## 파일의 신뢰도와 원본 6,317줄

**이 패키지는 원본 채팅 6,317줄의 문자 그대로의 복제본이 아닙니다.** 현재 대화에서 확인 가능한 주요 발언·선택을 자세하게 재구성했습니다. 원문 전체가 필요하면 ChatGPT 대화를 별도로 내보내 다음 경로에 보관하세요.

`docs/design/discussion-raw.md` (선택 파일, 이 패키지에는 없음)

이 원본이 추가되면 `AGENTS.md`의 문서 읽기 순서를 유지하고, 원본은 필요할 때만 검색하도록 하세요. 원문 아카이브보다 사용자의 최신 명시적 선택과 `redesign-spec.md`가 구현의 직접 기준입니다.

## 주요 주의사항

- `dist/redesign-preview/index.html`은 빌드 결과물입니다. 소스를 찾아 수정해야 합니다.
- 색상, 상세 이력 섹션 외형, 일부 정확한 치수는 미확정입니다.
- '우선 실험' 항목은 구현을 했더라도 사용자 화면 승인 전까지 확정하지 않습니다.
- 기능별 TDD와 화면 Visual QA를 함께 적용하되, 하나가 다른 하나를 대체하지 않습니다.
